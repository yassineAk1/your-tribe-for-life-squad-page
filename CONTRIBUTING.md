# Afspraken over samenwerking

## HTML conventies
1.Gebruik gestructureerde en semantische HTML  
2. Nest content niet onnodig diep. Voorkom te diepe nesting van section elementen en daarmee gepaarde heading levels. Link waar nodig liever naar een andere url met meer informatie  
3. Maak gebruik van ingebouwde features van HTML (bijvoorbeeld de krachtige form validation van formulier elementen)  
4. 1 tab – voor indentation.  
5. Gebruik dubbele quotes voor attributen.  
6. Gebruik altijd Engels in naamgeving in code!
